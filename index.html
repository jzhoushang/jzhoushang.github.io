Projects

Protein Simulation

Coarse-grained, three-dimensional protein simulation, using point-like amino acids and simplified forces to achieve results visually similar to real proteins with low complexity calculations.

The project is in JavaScript, using the Three.js library for rendering. It was designed to be visually interesting and easily viewable by web to serve as the front of this personal website.

Emerson Table Tennis Foundation Website

Website for the Emerson Table Tennis Foundation, a student-ran non-profit organization which raises money for Alzheimer's research at Mass General Hospital and cancer research at Dana-Farber.

The website built from scratch using the Hugo static site generator. The organization's online presence provides information about upcoming events, tournament results, and an online store used to sell merchandise.

BugBo

Online study tool for insect identification using the iNaturalist API made for the Science Olympiad's Entomology event.

The project is in pure HTML, CSS, and JavaScript to be easily accessible and shareable through GitHub Pages, which helped teammates practice. It was designed with many features to maximize the rate of identification, including autocomplete, image preloading, and the ability to enlarge the images.
